
# DERT – Connect the World

DERT is a global social networking application designed to connect people around the world.

## Our Vision
To build a modern, simple, secure, and user-friendly social platform.

## Main Features
- User registration and login
- Personal profiles
- Share photos and videos
- Posts, likes, and comments
- Private messaging
- Follow and discover people
- Notifications
- Search users worldwide

## Platforms
- iOS
- Android
- Web

## Project Goal
Building a global social network that brings people together.
